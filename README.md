# Duckling's Journey (귀여운 오리 가족 찾기) – 플레이 가능한 프로토타입

PRD를 바탕으로 만든 **모바일 웹 3D 프로토타입**입니다 (Three.js r128).
브라우저에서 바로 플레이할 수 있고, Capacitor로 감싸면 iOS/Android 앱으로 낼 수 있습니다.
이 PC에 Unity가 설치되어 있지 않아 웹으로 먼저 만들었습니다. 레벨 데이터와 물리 규칙은 Unity로 그대로 옮길 수 있게 단순하게 짜 두었습니다.

## 실행

```bash
python serve.py
```
→ PC 브라우저에서 http://localhost:8123 (방향키/WASD 또는 화면 조이스틱)

**폰에서 기울기로 테스트하기**: 기울기 센서는 HTTPS에서만 켜집니다(특히 iOS).
PC와 폰이 같은 Wi‑Fi라도 `http://<PC IP>:8123` 으로는 조이스틱만 나옵니다.
아래처럼 HTTPS 터널을 쓰면 됩니다:
```bash
npx localtunnel --port 8123
```

PRD에 없던 추가 요소: 레벨 2부터 **옆 물살(cross current)** 이 오리를 좌우로 천천히 밀어냅니다.
이게 없으면 가만히 있어도 클리어가 돼서 넣었습니다. 세기는 `levels.js`의 `cross` 값으로 조절합니다.
자동 조종 테스트 결과: 레벨 2~5는 아무 조작을 안 하면 떨어지고, 0.25초 반응 지연을 둔 조종으로는 모두 클리어됩니다.

## 파일

- `index.html`, `css/style.css` – 화면/HUD/팝업
- `js/levels.js` – 레벨 데이터 (직선 `S(길이, 벽)`, 코너 `C(각도, 반지름, 벽)`)
- `js/game.js` – 트랙 생성, 물리, 입력, 오리/가족 모델, 이펙트, UI
- `js/audio.js` – 합성 사운드
- `js/i18n.js` – 한국어/영어 문구
- 조정용 상수: `game.js` 맨 위 (`WATER_DRAG`, `INPUT_ACC`, `GYRO_FULL_DEG` 등)

## 안드로이드 앱 (APK)

- 결과물: `dist/DucklingsJourney.apk` (테스트용 debug 서명, 약 4.7MB, Android 5.1 이상, 세로 고정, 인터넷 없이 실행)
- 다시 만들기 (게임 수정 후): Git Bash 에서 `bash build-apk.sh`
- 빌드 도구: `C:\Users\leejj\android-build` (JDK 17, Android SDK 34, Capacitor 6 앱 프로젝트 `ducksway-app`)
- 아이콘·시작 화면: `tools/make-icons.js` 가 빌드할 때마다 생성
- 폰에 설치: APK 파일을 폰으로 옮긴 뒤(USB, 카카오톡 나에게 보내기, 구글 드라이브 등) 파일을 눌러 설치. 처음엔 "출처를 알 수 없는 앱 설치 허용"이 필요
- 앱 안에서는 기울기 센서가 HTTPS 없이 바로 동작
- 앱의 저장 데이터(별·기록·꾸미기)는 브라우저와 따로 저장됨
- 스토어(구글 플레이) 출시용은 별도 릴리스 서명 키로 다시 빌드해야 함
